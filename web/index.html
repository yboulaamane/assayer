Assayer is built on bio.tools, the ELIXIR registry, whose records are used under CC BY 4.0; on public GitHub repository metadata; and on our own curated stack of the tools a discovery project actually runs on. The selection, the staging and the protocols are ours. Structure data is fetched live from UniProt, RCSB PDB and AlphaFold DB. Nothing is computed here, the protocols are yours to run.
